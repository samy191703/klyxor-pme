1. Revalorisation automatique à date d'indexation
Complète
Identification automatique de la date anniversaire des contrats et lancement de la revalorisation prévue.

Éléments implémentés :

  • IndexationScheduler avec cron (tous les jours à 8h)
  • Détection automatique des contrats éligibles
  • ProposalService pour création des propositions
  • FormulaEngine pour calcul avec indices
  • ValidationBridge pour workflow de validation
  • ApplyService pour application après validation
  • Historisation complète dans indexation_proposals
  • Intégration INSEE API pour indices économiques

🎯 Recommandations Prioritaires

Actions à entreprendre pour atteindre 100% de conformité

  • Intégration SAP/Ampère : Développer les connecteurs pour le préremplissage automatique des données contractuelles lors de la création.
  • Format numéro de contrat : Implémenter le masque de saisie spécifique "T=[TypeContrat]-[Entité]-[Année]-[NuméroSéquentiel]".
  • Plan de facturation automatique : Générer automatiquement le plan basé sur le montant et la périodicité définie.
  • Template d'import standardisé : Créer un modèle Excel avec validation et rapport d'erreurs détaillé ligne par ligne.
  • Interface modification manuelle : Ajouter une interface dédiée avec champ de justification obligatoire pour les modifications manuelles de montants.
  • Sources indices additionnelles : Connecter Eurostat et Banque de France pour une couverture complète des indices économiques.
  • Gestion indices définitifs : Implémenter la distinction entre indices provisoires et définitifs avec mise à jour automatique.
